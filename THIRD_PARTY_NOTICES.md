## Bundled TeX core

`tex-core.bundle` contains runtime files assembled from official TeX Live package archives distributed through CTAN. The bundle includes LaTeX base classes, Computer Modern and AMS fonts, graphics and AMS mathematics support, and the small dependency packages required by those components. TeXwell keeps this deliberately smaller than a full TeX Live installation; users may add project-specific packages as normal project files.

The LaTeX3 kernel and backend files are from the official `latex3/latex3` 2020-02-14 release so they remain compatible with the bundled SwiftLaTeX format. LaTeX and supporting packages retain their upstream LaTeX Project Public License (LPPL) or other package-specific licenses; font files retain their upstream font licenses. Package metadata and source archives are available from <https://ctan.org/> and <https://github.com/latex3/latex3/releases/tag/2020-02-14>.

The bundle manifest is generated by `scripts/build-tex-core-bundle.mjs`; it does not modify the package runtime files except to select the format-compatible archived versions of `amsmath.sty` and `graphics.sty`, and to assemble the standard PDF font map from the bundled Computer Modern map fragments.
